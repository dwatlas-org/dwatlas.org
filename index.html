DeliveryWorkerAtlas

Plataforma de pesquisa

Dados e pesquisa sobre trabalhadores de entrega por aplicativo

O Delivery Worker Atlas é uma plataforma aberta de pesquisa dedicada à produção, organização e visualização de dados sobre o trabalho mediado por plataformas digitais. O projeto combina dados produzidos por trabalhadores, pesquisa acadêmica e tecnologias de código aberto para ampliar o conhecimento sobre as condições de trabalho na economia de plataformas.

Sobre o projeto

Compreender o trabalho em plataformas a partir dos dados

O Delivery Worker Atlas desenvolve ferramentas digitais que permitem documentar diferentes dimensões do cotidiano de trabalhadores de entrega por aplicativo, como ganhos, despesas, tempo de trabalho, deslocamentos e características das jornadas. Esses registros são organizados e transformados em indicadores agregados que podem apoiar pesquisas acadêmicas, análises públicas e debates sobre as transformações contemporâneas do trabalho.

Dos dados ao conhecimento público

Registros individuais para um debate coletivo

Os dados utilizados pelo Delivery Worker Atlas são produzidos a partir dos registros realizados pelos próprios trabalhadores em ferramentas digitais desenvolvidas pelo projeto. Após a coleta, os dados passam por processos de organização, validação, anonimização e tratamento, dando origem a indicadores e visualizações que permitem analisar diferentes aspectos do trabalho em plataformas sem expor informações individuais. Nosso objetivo é construir uma infraestrutura transparente, documentada e reutilizável para a produção de conhecimento sobre o trabalho de entrega por aplicativo.
